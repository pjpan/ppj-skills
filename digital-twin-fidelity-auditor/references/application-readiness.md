# Application Readiness Rubric

Application readiness is downstream of fidelity, but is not the same thing.

## Task Utility

Define the real task:
- draft;
- retrieve;
- analyze;
- recommend;
- decide;
- execute.

Measure task outcomes: time saved, human correction rate, acceptance rate, objective quality, completion rate, or other task-relevant outcomes.

## Substitutability

Use levels rather than one binary label:

- L0: reference only;
- L1: assist;
- L2: draft / propose;
- L3: recommend with human confirmation;
- L4: low-risk autonomous decision/action;
- L5: broader delegated action under explicit policy.

Do not infer substitution from style similarity.

## Risk Readiness

Classify errors by consequence:
- reversible / low impact;
- recoverable / moderate;
- costly;
- identity/reputation sensitive;
- safety/legal/financial critical.

Required evidence and controls should increase with risk.

## Authorization Readiness

Check:
- who grants permission;
- which tasks/actions are allowed;
- scope/duration;
- human approval thresholds;
- revocation;
- logging/audit;
- external representation restrictions.

A system can be technically capable but unauthorized.
